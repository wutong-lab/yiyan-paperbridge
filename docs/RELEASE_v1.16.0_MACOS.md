# 译研 1.16.0 · 全屏对照与彩色批注

**[Mac 一键安装](https://github.com/wutong-lab/yiyan-paperbridge/releases/download/v1.16.0-macos/Yiyan-Mac-OneClick-Setup.dmg)** · **[Windows 一键安装](https://github.com/wutong-lab/yiyan-paperbridge/releases/download/v1.16.0-windows-update/Yiyan-Windows-OneClick-Setup.exe)**

- 简洁的浅色工作台，突出论文、翻译设置与阅读操作。
- 全屏中英对照，支持左右独立缩放、联动缩放和同步滚动；F 进入，Esc 退出。
- 原文和译文均可高亮或划线，提供鲜明预设色和自由选色盘，自动记住常用颜色。
- 批注自动保存，支持多行文字、缩放与翻页后定位，原文和译文分别导出带批注的 PDF。
- 批注保存、删除与导出期间显示状态；重试不会重复生成批注，删除的批注不会因迟到请求重新出现。

本地 4B / 14B、已配置 API、批量翻译、表格翻译开关、术语、用时统计和资源清理继续保留。更新继续使用已安装模型、论文、API 配置和译稿。

安装方法见 [Mac 教程](https://github.com/wutong-lab/yiyan-paperbridge/blob/main/docs/MAC_INSTALL.md) 与 [Windows 教程](https://github.com/wutong-lab/yiyan-paperbridge/blob/main/docs/WINDOWS_INSTALL.md)。
