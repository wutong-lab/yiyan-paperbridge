# 译研 Mac 安装与更新教程

**[下载 Mac 一键安装器](https://github.com/wutong-lab/yiyan-paperbridge/releases/download/v1.8.4-macos/Yiyan-Mac-OneClick-Setup.dmg)** · [备用加速下载](https://ghfast.top/https://github.com/wutong-lab/yiyan-paperbridge/releases/download/v1.8.4-macos/Yiyan-Mac-OneClick-Setup.dmg) · [软件首页](../README.md)

打开安装器，选择 4B 或 14B，点击“下载并安装”。应用、所选模型、字体和排版环境会自动装好，之后可直接离线使用。

## 选择模型

| 配置 | 4B 标准版 | 14B 精译版 |
|---|---|---|
| 电脑 | Apple Silicon（M 系列）Mac | Apple Silicon（M 系列）Mac |
| 系统 | macOS 26.2 或更新 | macOS 26.2 或更新 |
| 建议统一内存 | 16GB 或更多 | 24GB 或更多 |
| 模型大小 | 约 2.15GB | 约 7.86GB |
| 应用与运行环境 | 另约 0.6GB | 另约 0.6GB |
| 安装预留空间 | 15GB | 30GB |

日常论文阅读可先选择 4B；处理复杂长句和专业表达可选择 14B。两版都在本机运行，使用相同的专业词库、公式保护与排版流程。

## 一键下载安装

![选择 4B 或 14B 后一键安装](images/macos-setup.png)

1. 下载并打开 `Yiyan-Mac-OneClick-Setup.dmg`。
2. 双击里面的 **安装译研**。首次打开若 macOS 提示需要确认，可在“系统设置 → 隐私与安全性”中允许打开安装器。
3. 选择 **4B 标准版**或 **14B 精译版**，按需更改安装位置。
4. 点击 **下载并安装**。向导自动下载、校验并安装全部内容。
5. 出现“安装完成”后打开 **译研**，导入论文即可翻译。

安装器自行直连网络，无需配置本机代理，也不会修改系统代理设置。GitHub 直连较慢或中断时，自动切换备用加速线路并续传；下载完成后核对文件大小和 SHA256。界面显示当前线路、实时速度与预计剩余时间。

下载可以暂停，之后点击继续或重新打开安装器即可续传；网络中断会自动重试。默认勾选“装好后清理下载缓存”和“安装完成后打开译研”。

首次安装需要联网。安装完成后，模型推理、中英对照与 PDF 导出在本机离线运行。

## 更新软件，保留模型

打开译研，在屏幕顶部菜单选择 **译研 → 检查更新**。发现新版本后点击 **下载并更新**，程序会启动更新向导并退出当前窗口。等待更新完成，再打开译研。

更新只替换应用和运行环境。已经安装的模型、导入的论文、译稿和专业词表继续保留。正在处理论文时，先等任务完成再更新。

也可以重新打开一键安装器，选择原来的模型与安装位置。已完整安装的模型会复用，向导只补充需要下载的内容。

## 模型与论文存在哪里

模型放在应用之外的固定目录：

```text
~/Library/Application Support/PaperBridge-Offline/models
```

论文、译稿和设置保存在同一工作室的其他目录中。更新或替换 `译研.app` 不会删除这些内容。旧完整离线版的内置模型会在替换应用前迁入独立模型目录，迁移过程中核对文件校验值。

应用可装在“应用程序”或你选择的文件夹中；默认位置没有写入权限时，向导使用个人“应用程序”文件夹。

## 开始翻译

1. 点击“选择论文 PDF”，或拖入一篇、多篇英文论文。
2. 选择学科、页码和已安装的本地模型，点击“开始翻译”。
3. 翻译后左右对照原文与中文，可同步翻页、滚动和缩放。
4. 通过“导出”保存中文 PDF、双语 PDF 或完整译文记录。

## 常见情况

| 情况 | 操作 |
|---|---|
| 提示“安装归档包含无效路径” | 下载 1.8.4 或更新安装器，关闭旧向导后重新打开，选原来的模型与位置；已下载的模型缓存继续复用 |
| 下载中途断开 | 保留下载缓存，再次点击继续 |
| 提示译研正在运行 | 先等论文处理完成，退出译研后继续安装 |
| 需要增加另一模型 | 打开安装器选择另一模型，或从软件的模型窗口下载 |
| 想检查存储和清理缓存 | 在工作室右上角打开“内存 / 存储” |
| 暂时无法检查更新 | 联网后重试；已装好的版本可以继续离线翻译 |

## 下载服务

应用和模型托管在 GitHub，由 GitHub 或公共加速通道分发；下载不连接开发者的个人电脑。备用线路由 ghfast.top、gh-proxy.com 提供，只传输公开安装资源。版本清单通过项目仓库及 jsDelivr 公共 CDN 获取，安装器内置本版安装清单与固定模型校验值。论文继续在本机处理。
