# 译研 1.13 · Mac / Windows

**[Mac 一键安装器](https://github.com/wutong-lab/yiyan-paperbridge/releases/download/v1.13.0-macos/Yiyan-Mac-OneClick-Setup.dmg)** · **[Windows 一键安装器](https://github.com/wutong-lab/yiyan-paperbridge/releases/download/v1.13.0-windows-update/Yiyan-Windows-OneClick-Setup.exe)**

- 保存 DeepSeek 或其他 OpenAI 兼容 API 配置，翻译时直接选择本地模型或常用服务。
- 使用 macOS 钥匙串 / Windows DPAPI 保存个人密钥；记录翻译用时和 API token 用量。
- 加强跨页段落衔接、表格与图注上下文、专业译名一致性。
- 本地翻译开始前检查内存、显卡，支持明确的配置不足、加载超时与生成异常提示。
- 保留 4B / 14B 一键安装、离线翻译、左右同步阅读、独立缩放和 PDF 导出。
- 更新应用时继续使用已安装的模型，保留工作室里的论文、译稿和设置。
