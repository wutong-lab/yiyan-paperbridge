# 译研 1.15.1 · 按需翻译表格文字

**[Mac 一键安装](https://github.com/wutong-lab/yiyan-paperbridge/releases/download/v1.15.1-macos/Yiyan-Mac-OneClick-Setup.dmg)** · **[Windows 一键安装](https://github.com/wutong-lab/yiyan-paperbridge/releases/download/v1.15.1-windows-update/Yiyan-Windows-OneClick-Setup.exe)**

在 **翻译设置 → 更多设置** 中新增 **翻译表格文字**，默认关闭。表格内部保留英文、数值和排版；勾选后翻译可识别的表格文字。表题和表注继续翻译。

本地模型、已配置的 API 和批量任务使用相同设置。关闭时表格内容不参与模型翻译或自动术语提取；开启时继续使用表格语境与数值、公式保护。表格中的手动校订会保存在任务记录中。

Mac 与 Windows 共用处理代码；更新继续使用已经安装的模型、API 配置和论文。

本版同时加强 Windows 本地推理的译文输出格式，改善短段落与表注的翻译稳定性。
