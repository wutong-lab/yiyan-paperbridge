# 本地模型与 API 翻译

译研 1.14 的 Mac、Windows 版本使用相同的翻译工作室。选择本地 4B / 14B 可以离线运行；选择 API 则使用你保存的大模型服务。

## 保存常用服务

1. 打开软件，点击 **API 配置**。Mac 也可从 **文件 → API 配置** 进入，Windows 可从 **软件 → API 配置** 进入。
2. 添加配置，选择 DeepSeek、通义千问、硅基流动或 **自定义 OpenAI 兼容接口**。
3. 填写自己的 API 密钥、Base URL 和服务商提供的完整模型名称。
4. 点击 **保存并测试**。测试会发送少量请求，可能产生服务商计费。
5. 导入论文，在翻译服务中选择已保存的配置，点击开始翻译。以后直接选择该配置即可。

自定义服务需要支持 Chat Completions 格式；Base URL 通常以 `/v1` 结尾，按服务商文档填写。JSON 模式和流式用量开关根据接口能力设置。

Mac 把密钥保存在登录钥匙串，Windows 使用当前用户的 DPAPI 加密保存。配置列表显示服务名称和模型，不显示完整密钥。重新打开软件可继续使用已保存的配置；更换服务地址时需重新填写相应密钥。

API 翻译会把所选待译文本、必要的术语和上下文发给你配置的服务。用量记录显示服务商返回的输入、输出和缓存 token；实际费用以服务商账单为准。

## 本地模型与电脑配置

| 使用方式 | 内存要求 | 显卡要求 |
| --- | --- | --- |
| Mac 本地 4B | 至少 16GB 统一内存 | Apple Silicon 集成 GPU |
| Mac 本地 14B | 至少 24GB 统一内存 | Apple Silicon 集成 GPU |
| Windows 本地 4B，CPU | 至少 16GB | 支持没有独立显卡的电脑 |
| Windows 本地 14B，CPU | 至少 24GB，建议 32GB+ | 需要确认使用较慢的 CPU 模式 |
| Windows 本地 4B，NVIDIA 完整加速 | 至少 8GB，建议 16GB+ | 至少 6GB 可用显存，建议 8GB+ |
| Windows 本地 14B，NVIDIA 完整加速 | 至少 16GB，建议 24GB+ | 至少 12GB 可用显存，建议 16GB+ |
| API 翻译 | 不加载本地大模型；大型 PDF 仍需要解析、排版空间 | 无需独立显卡 |

这些是软件对固定量化模型和上下文长度的支持预算。软件会检查实际内存、可用内存和显存；内存不足时提供切换 4B / API 的提示。模型加载超时、生成超时或内存分配失败时，任务会停止并保留已完成内容。

安装器选择 4B 或 14B 自动准备完整离线环境。后续通过菜单检查更新，继续使用本机模型和个人设置。
