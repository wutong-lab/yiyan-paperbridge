# 译研 Windows 安装与使用教程

译研把 SCI 英文论文翻译成专业中文，支持原文／译文左右对照、同步翻阅、专业词表与 PDF 导出。下载一个 **Windows 一键安装器**，选择 **4B 标准版**或 **14B 精译版**，向导自动下载、校验并安装完整环境。安装后导入论文即可离线翻译。

## 已经安装过：保留模型更新

新版在顶部菜单提供 **软件 → 检查更新**。确认后打开更新向导，点击“检查并更新应用”；完成后继续离线翻译。普通更新只下载应用包，原来的 4B / 14B 模型、论文、译稿、术语和设置继续保留，也复用已有运行环境。

从旧版首次升级，重新下载上面的一键安装器，选择原来的模型和安装位置。检测到完整模型后直接更新应用，无需重新下载模型。默认安装位置也可以使用 [单独更新工具](https://github.com/wutong-lab/yiyan-paperbridge/releases/download/v1.15.0-windows-update/Yiyan-Updater.exe)。

后续版本与接口维护见 [Windows 更新发布说明](WINDOWS_RELEASE_MAINTENANCE.md)。

## 1. 选择适合电脑的模型

| 配置 | 4B 标准 | 14B 精译 |
| --- | --- | --- |
| 操作系统 | Windows 10 2004+ / Windows 11，64 位 x64 | Windows 10 2004+ / Windows 11，64 位 x64 |
| 处理器 | 支持 AVX2 的 Intel / AMD 64 位处理器，4 核起 | 支持 AVX2 的 Intel / AMD 64 位处理器，6 核起 |
| 电脑内存最低配置 | **16GB RAM** | **24GB RAM** |
| 电脑内存建议配置 | **16GB 或更多** | **32GB 或更多** |
| 完整 GPU 加速的显存配置 | NVIDIA **6GB 起，建议 8GB+** | NVIDIA **12GB 起，建议 16GB+** |
| CPU 运行 | 支持，使用上面的电脑内存配置 | 支持，使用上面的电脑内存配置 |
| 内置模型大小 | **约 2.50GB** | **约 9.00GB** |
| 基础离线环境下载大小 | **约 4.07GB** | **约 10.49GB** |
| 用户下载安装入口 | 同一个一键安装器，选择 4B | 同一个一键安装器，选择 14B |
| 安装及使用预留磁盘空间 | **15GB** | **30GB** |

首次安装会在基础环境就绪后自动获取当前应用版本；后续更新只下载应用包。

同时安装两个模型建议预留 **40GB** 磁盘空间。应用及论文也需要空间，模型文件大小和运行内存是不同的数字。

表中的容量是本软件按 **Qwen3 Q4_K_M、8192 token 上下文、单任务、FP16 KV 缓存**预留推理与排版开销后的配置预算。显存指单张 NVIDIA 显卡可用的独立显存；运行大型游戏或其他模型时，应先释放相应资源。这里的最低配置用于选择模型，实际占用会随论文内容和后台程序变化。

**选哪个：** 日常阅读和较低配置先选 4B；希望更充分处理长句、复杂关系及专业表达时选择 14B。两种模型沿用相同的专业术语、数值与公式检查和排版流程。

**是否一定要独立显卡：** 两种模型都支持 CPU。显卡用于加速；软件检测到可用显存充足的 NVIDIA 显卡时优先使用 GPU，其他情况使用 CPU。AMD、Intel 显卡电脑可使用 CPU 模式。

NVIDIA 加速组件使用 CUDA 12.4，建议安装 **551.61 或更新版本的 NVIDIA 驱动**；应用内附所需推理运行库。依据：[NVIDIA CUDA 12.4 驱动说明](https://docs.nvidia.com/cuda/archive/12.4.0/cuda-toolkit-release-notes/index.html)。

## 2. 一键下载安装

![选择模型后点击下载并安装](images/windows-setup.png)

1. 下载上面的 **`Yiyan-Windows-OneClick-Setup.exe`**，双击打开。
2. 选择 **4B 标准版**或 **14B 精译版**；按需更改安装位置。
3. 点击 **下载并安装**。向导会自动获取完整安装文件、核对 SHA256，并安装模型、运行环境、阅读组件、字体与排版资源。
4. 显示“安装完成”后打开 **译研**，导入论文即可离线翻译。

下载时可以点击 **暂停下载**，之后点击继续或重新打开向导，都能接着下载。网络暂时中断时向导会自动重试或切换备用线路。安装和更新连接自行直连，不修改系统代理设置。默认勾选 **装好后清理下载缓存**与 **安装完成后打开译研**。

首次下载安装需要联网。安装完成后，全文翻译、中英对照与 PDF 导出在本机离线运行。Windows 如果提示需要安装运行库，按系统提示允许内置的 Microsoft 官方组件安装即可。

### 为完全离线的电脑准备安装文件

也可以选择 [4B 完整离线包](https://github.com/wutong-lab/yiyan-paperbridge/releases/tag/v1.6.0-windows-4b-offline)或 [14B 完整离线包](https://github.com/wutong-lab/yiyan-paperbridge/releases/tag/v1.6.0-windows-14b-offline)。在对应页面下载 `Setup.exe` 及全部 `.bin`，放在同一个文件夹后运行安装程序；4B 共 3 个数据分卷，14B 共 6 个数据分卷。全部文件备好后可以拷贝到离线电脑上安装。

## 3. 内置模型与切换

4B 完整版默认选中 **标准 · 4B**；14B 完整版默认选中 **精译 · 14B**。模型直接从应用目录的 `Models` 读取，首次启动不会复制第二份。

如果想增加另一种模型，可在模型窗口查看本机配置并点击对应下载按钮，或安装另一完整版。按需增加模型需要联网，完成后可离线使用。已经导入的论文与译稿保留在个人数据目录。

需要较小的首次下载时，也可选择 [1.5 按需下载版](https://github.com/wutong-lab/yiyan-paperbridge/releases/tag/v1.5.0-windows)：安装后在模型窗口下载 4B 或 14B，再进行离线翻译。

## 4. 翻译论文并切换模型

1. 点击 **选择论文 PDF** 或拖入英文论文；可以一次放入多篇。
2. 展开 **翻译设置 → 更多设置 → 本地模型**，选择 **标准 · 4B** 或 **精译 · 14B**。
3. 选择学科、翻译页码、术语及译后复核设置，点击 **开始翻译**。
4. 完成后在左右两栏对照阅读，同步滚动并独立或联动放大。
5. 在 **导出** 中选择中文 PDF、原译交替双语 PDF 或完整译文记录。

适用正文可以选择、复制的英文 PDF；单篇 80MB 以内、300 页以内。4B 与 14B 按论文任务选择，依次处理队列；切换时会释放上一任务的模型资源。

## 5. 专业词表、内存与存储

- 在 **专业术语表** 中选择学科词库，并添加 `English term = 中文译名`。
- 在右上角 **内存 / 存储** 中查看占用，选择清理临时文件、旧自动备份、下载缓存或日志。
- 开启 **完成后自动清理**，任务完成后整理临时资源；推理进程结束后释放内存和显存。

论文、译稿、按需下载的模型和设置保存在 **`%LOCALAPPDATA%\PaperBridge`**；完整版内置模型保存在应用安装目录的 **`Models`**。个人数据与应用文件分开存放。

## 常见操作

| 情况 | 处理方法 |
| --- | --- |
| 想先体验、电脑内存 16GB | 选择 4B 标准模型 |
| 14B 下载或加载占用较大 | 按配置表释放内存，或在任务设置中切换到已安装的 4B |
| 有 NVIDIA 显卡但显示 CPU | 关闭其他占用显存的程序，并更新 NVIDIA 驱动后重新开始任务 |
| 下载到一半中断 | 保留下载缓存，再次点击对应模型的下载按钮 |
| 想更换安装目录 | 安装到新目录，重新打开译研；个人数据继续从上面的用户目录读取 |
| 想查看本地运行记录 | 打开 `%LOCALAPPDATA%\PaperBridge\tmp`，以及对应论文任务中的 `full-worker.log` |

## 模型与开源来源

Windows 版使用 Qwen 官方 [Qwen3-4B-GGUF](https://huggingface.co/Qwen/Qwen3-4B-GGUF) 与 [Qwen3-14B-GGUF](https://huggingface.co/Qwen/Qwen3-14B-GGUF) 的 **Q4_K_M** 文件，由 [llama.cpp](https://github.com/ggml-org/llama.cpp) 在本机运行。下载固定到具体版本，并在启用前校验 SHA256。

应用源码使用 AGPL-3.0；Qwen 模型使用 Apache-2.0；llama.cpp 使用 MIT。对应源码与依赖许可随应用提供，见 [第三方声明](../THIRD_PARTY_NOTICES.md)。


## 选择 API 翻译

打开工作室中的 **API 配置**，添加服务并保存测试。翻译时选择保存好的配置即可。密钥由系统加密保存，重启软件后仍可使用。API 模式需要联网，无需加载本地模型。详细步骤见 [API 配置](API_SETUP.md)。

## 表格文字翻译

在论文的 **翻译设置 → 更多设置** 中找到 **翻译表格文字**。默认关闭，表内原文与数值保持原貌；需要中文表头或文字单元格时勾选后翻译。表题和表注继续翻译。批量任务沿用当前选择，已保存的任务会记住本篇设置。
