# 译研 Mac 1.4 完整离线版

本安装包包含本地 Qwen3-14B 4bit 精译模型、Qwen3-4B 4bit 标准模型、全文排版模型、字体、字符映射及 Python 运行环境。
它使用与本机开发版相同的权重文件，没有降低量化精度，没有模型 API，也不需要先下载模型。
“14B 原版”在本发行包中特指原本安装的 `Qwen/Qwen3-14B-MLX-4bit` 快照，不是未量化的 FP16 权重。

## 安装与使用

1. 下载完整 DMG；如果从 GitHub 下载分卷，则下载全部 `.part001`、`.part002` 等文件，以及 `合并安装包.command`、`PARTS-SHA256.txt`、`PARTS.json` 到同一个文件夹。
2. 双击 `合并安装包.command`，工具会逐卷核对 SHA256、合并并校验完整 DMG，不需要安装 Python 或其他解压软件。`.partNNN` 是顺序分片，需要先合并再打开。
3. 打开 `Yiyan-1.4.0-AppleSilicon-Offline-14B.dmg`，将“译研”拖到“应用程序”。
4. 从“应用程序”打开译研；首次将内置排版资源准备到用户工作室，模型直接使用应用内的权重，不复制第二份约 10GB 模型。
5. 顶部应显示“本地模型已就绪”。导入英文 PDF，默认选择 14B 精译，即可离线翻译、左右对照和导出。

需要 **Apple Silicon、macOS 26.2 或更新版本**。14B 精译建议至少 24GB 统一内存。安装应用约 11GB；分卷、合并 DMG 和安装副本同时存在时，建议预留 35GB 可用空间。
此包使用临时签名，尚未通过 Apple Developer ID 签名和公证；确认文件来源、核对 SHA256 后，按 [Apple 官方说明](https://support.apple.com/zh-cn/102445) 处理首次打开提示。
安装后不要在任务运行期间移动或删除应用。升级前退出旧版本；已下载到用户数据目录的独立模型优先保留。

论文、译稿和任务保存在 `~/Library/Application Support/PaperBridge-Offline/`，不放进应用包。离线版使用独立工作室，原有版本的论文和任务保持原位置。
软件不会上传论文。测试材料是合成文档，没有把你的论文、译稿、日志、翻译缓存或任务数据库打包进去。
卸载应用时，内置模型一并移除，用户论文及译稿仍保留。

## GitHub 发布

普通代码仓库仅上传公开源码，不提交模型和 DMG 到 Git 历史。
完整版分卷、合并工具、校验文件、安装说明及源码 ZIP 放到同一 GitHub Release。GitHub 每个附件要求小于 2GiB，所以完整离线 DMG 会拆成多个小于限制的部分。
公开分发时保留 AGPL-3.0 应用许可、Qwen 模型的 Apache-2.0 许可、字体与排版资源的原许可，并提供应用及第三方对应源码。
这次生成发行材料，不会自动创建或公开远程仓库。

源码构建完整版：

```sh
.venv/bin/python scripts/package_macos.py --include-models --python-runtime /path/to/standalone/python
```

本版本不承诺所有 SCI PDF 的语义和版面完全正确；扫描页尚不支持 OCR，复杂公式附近的语义、跨栏顺序和表格仍可能需要核对。


## 本地模型 / API

在工作室打开“API 配置”，填写自己的服务地址、模型和密钥，保存测试后可在翻译时直接选择。支持 DeepSeek 和 OpenAI 兼容接口；Mac 钥匙串 / Windows DPAPI 加密保存密钥。选择 API 会联网发送待译内容与必要上下文；本地模型支持离线使用。
